# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release. Older releases are not guaranteed to receive security fixes; please update to the latest release before reporting an issue.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately using [GitHub's private vulnerability reporting form](https://github.com/mocchii2/Separan/security/advisories/new). Do not report security vulnerabilities in public issues, discussions, or pull requests.

Include the affected component and version, operating system, steps to reproduce, and potential impact. Please do not include real credentials, tokens, or other secrets in the report.

We will acknowledge and assess reports as time permits. Please allow coordinated disclosure before making details public. No response-time commitment is offered.

## 日本語

### サポート対象

セキュリティ修正は最新の安定版を対象とします。古いバージョンへの修正提供は保証されません。報告前に最新バージョンへ更新してください。

### 脆弱性の報告

脆弱性の疑いがある問題は、[GitHub の非公開報告フォーム](https://github.com/mocchii2/Separan/security/advisories/new)から報告してください。公開 Issue、Discussion、Pull Request には投稿しないでください。

影響するコンポーネントとバージョン、OS、再現手順、想定される影響を記載してください。実際の認証情報、トークン、その他の秘密情報は含めないでください。

報告は可能な範囲で確認します。詳細を公開する前に、修正に向けた調整の機会を設けてください。回答時間は保証できません。
